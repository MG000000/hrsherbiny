# حضوري — واجهة حضور وانصراف على مستندات ERPNext الأصلية

كل الملفات في مكان واحد (من غير فولدرات)، فارفعها كلها على الـ repo زي ما هي.

## المستندات المستخدمة (كلها أصلية في ERPNext و HRMS)

| الوظيفة | المستند |
|---|---|
| البصمة | Employee Checkin |
| الشيفتات والسماح اليومي والأوفر تايم | Shift Type (Late Entry / Early Exit Grace Period، Allow Overtime، Overtime Type) |
| تعيين الموظف على شيفت وفرع | Shift Assignment + Shift Location |
| بصمة متأخرة أو انصراف مبكر بعد السماح | Attendance Request (موافقة HR) |
| بصمة في شيفت غير شيفته | Shift Request (موافقة Shift Approver) |
| الإجازات | Leave Application + Leave Type (الإجازة بدون مرتب بتتخصم لوحدها في الـ Payroll) |
| المكافآت والخصومات وخصم التأخير والأوفر تايم | Additional Salary |
| المرتب الأساسي | Salary Structure Assignment |
| المهام | ToDo |
| الإشعارات | Notification Log |
| الصلاحيات | أدوار ERPNext نفسها |

## الصلاحيات

| الدور | بيشوف |
|---|---|
| System Manager / HR Manager | كل حاجة + الشيفتات والتعيين والفروع والموظفين + إرسال للمرتب |
| HR User | الحضور اليومي، كل الطلبات، المكافآت والخصومات، تقرير كل الموظفين |
| Leave Approver / Shift Approver | الطلبات اللي هو المسؤول عنها |
| Employee | البصمة، طلباته، مهامه، تقريره، مكافآته |

كل يوزر بيدخل بحسابه، والواجهة بتطلّع له مفتاح API خاص بيه، فـ ERPNext نفسه هو اللي بيمنع أي حد يعمل حاجة مش من صلاحياته.

## قبل التشغيل

1. **CORS:** من Frappe Cloud، Site Config، ضيف `"allow_cors": ["https://mg000000.github.io"]`.
2. **Salary Components:** اعمل المكونات دي (الأسامي لازم تطابق `COMPONENTS` في `config.js`):
   - `خصم التأخير` (Deduction)
   - `خصم نسيان البصمة` (Deduction)، واكتب في خانة **Amount** المبلغ اللي بيتخصم كل مرة
   - `أوفر تايم` (Earning)، ده لو الشيفت مالوش Overtime Type
   - `مكافأة` (Earning)
   - `خصم إداري` (Deduction)
3. **HR Settings:** علّم على **Allow Multiple Shift Assignments for Same Date** عشان الموظف اللي شغال في فرعين.
4. **كل موظف:** لازم يكون له User ID و Salary Structure Assignment.
5. **Leave Types:** اعمل نوع إجازة واحد على الأقل معلّم عليه **Is Leave Without Pay**.

## قواعد في `config.js`
الحاجات دي مالهاش خانة أصلية في ERPNext:
- `MONTHLY_GRACE_MINUTES`: رصيد السماح الشهري (100 دقيقة)
- `LATE_MULTIPLIER`: معامل ضرب الدقائق الزيادة (2)
- `WORKING_DAYS_PER_MONTH`: لحساب سعر الدقيقة (26)

مثال: سماح 100، والموظف اتأخر 120 دقيقة، والمعامل 2 ← (120 − 100) × 2 = 40 دقيقة × سعر دقيقته.

## تنبيهات مهمة
- **مفتاح الأدمن لسه في الكود.** بيتستخدم وقت الدخول بس (عشان يطلّع مفتاح لكل يوزر) وفي الإشعارات. أي حد يفتح كود الصفحة يقدر يشوفه. بعد التجربة اعمل له Regenerate.
- **كل مرة اليوزر يدخل بيتعمله مفتاح API جديد.** يعني لو دخل من موبايل تاني، الأول هيطلب منه يدخل تاني. ولو يوزر مفتاحه مستخدم في حاجة تانية (زي أداة البصمة ZK)، **متدخلش بيه على الواجهة** عشان المفتاح هيتغير والأداة هتقف. اليوزر اللي مفتاحه في `config.js` مستثنى من ده.
- **بصمة الوجه:** أول مرة الموظف يبصم، الواجهة بتاخد 3 لقطات لوشه وتحفظ البصمة كملف مرفق في ملفه على ERPNext (اسمه بيبدأ بـ `face-enroll-`)، ومعاها صورة. بعد كده كل بصمة بتتقارن بيها. الموظف مش بيقدر يسجّل تاني، ولو عايز يغيّرها، الموارد البشرية بتمسحها من شاشة **الموظفين**. الموارد البشرية بيوصلها إشعار أول ما حد يسجّل، وتقدر تشوف الصورة. محتاجة الصفحة تكون https.
